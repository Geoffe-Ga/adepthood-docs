# Products

Per-product overviews: what each repo in the ecosystem is, who it serves,
its current feature surface, and how it relates to the others.

## Inclusion criteria

File a page (or update an existing one) here when a merged PR:

- Adds, removes, or materially changes a user-facing feature.
- Changes a product's scope, audience, or positioning.
- Ships a milestone worth reflecting in the product's overview (a phase of
  the roadmap completing, a platform launch).
- Creates a new repo or archives an existing one.

Do **not** file here for: internal refactors invisible to users
([Architecture](../architecture/index.md)), or visual changes
([Design](../design/index.md)).

## Conventions

One page per repo, named after it:

- `adepthood.md` — React Native + FastAPI graduated-engagement journal and
  36-week APTITUDE program companion.
- `creek-vault.md` — Creek-Vault.
- `wavelengthwatch.md` — WavelengthWatch.
- `aptitude-course.md` — aptitude-course.
- `wavelength-demo.md` — wavelength-demo.

Each page opens with a one-paragraph elevator pitch, then feature surface,
then cross-repo relationships.
